### 1. AgroBridge — Connecting Farmers & Agro Enthusiasts

![AgroBridge hero](https://agrobridge-web.netlify.app/og-image.png)

**GitHub Description Helper:** `AgroBridge · Community platform linking farmers & agro-enthusiasts with listings, trades, and knowledge threads. Live: https://agrobridge-web.netlify.app · Stack: React (Vite) · Tailwind · Firebase Auth · Node · Express · MongoDB`

- **Overview:** Modern marketplace and knowledge hub where farmers publish listings, manage interests, and open secure chats with buyers.
- **Main Features:** Crop marketplace, listing CRUD with media upload, favorites list, authentication, advanced search/filtering, responsive UI.
- **Tech Stack:** React 18, Vite, Tailwind CSS, Firebase Auth, Node.js, Express.js, MongoDB, REST API, ESLint.
- **Dependencies:** `react`, `react-router-dom`, `vite`, `tailwindcss`, `firebase`, `axios`, `express`, `mongoose`, `cors`, `dotenv`, `jsonwebtoken`.
- **Live:** https://agrobridge-web.netlify.app
- **Repos:** [Client](https://github.com/dev-rakibul-islam/AgroBridge-Client) · [Server](https://github.com/dev-rakibul-islam/AgroBridge-Server)

**Run locally (client)**

```bash
git clone https://github.com/dev-rakibul-islam/AgroBridge-Client.git
cd AgroBridge-Client
npm install
npm run dev
```

**Run locally (server)**

```bash
git clone https://github.com/dev-rakibul-islam/AgroBridge-Server.git
cd AgroBridge-Server
npm install
npm run dev
```

> Add `.env` files with your Firebase config, MongoDB URI, JWT secret, and any third-party API keys before running the services.

### 3. Roystyle — Motion-rich E-Commerce Drops(Private Repo)
